Solmar Keys — an original top-down 2D open-world driving/action game inspired by GTA 6. Drive a procedural island city, take on 3 story missions for Rico Vega, dodge (or outrun) the police as your wanted level climbs from 0 to 5 stars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly in a browser.
